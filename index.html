New here? The two engines on the top row are free: follow the link on either, sign in, create a key, then paste it here. The key is kept only for this browser session and sent only to the engine you chose. It is never stored on our server.

Named for and inspired by Roald Dahl's 1953 short story of the same name, about a machine built to churn out fiction on demand. This app takes that premise semi-literally: a language model standing in for Dahl's fifty thousand cogs and valves. Read about the story or get it from the publisher.
